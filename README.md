# hxyfront-62011 蹄铁上门 · 预约风险排程

面向马术俱乐部蹄铁师上门作业的预约风险排程前端。

## 功能

- 每匹马记录：抬蹄耐受、最近踢踏史、所需助手、到场时段
- 系统依据耐受与踢踏史给出风险建议评级，可手动改评级（普通 / 高风险）
- 高风险马须两名蹄铁师双确认、且助手确认到场、且时段无重叠才能占时段（可作业）
- 助手未确认或时段与更早的已占单重叠时退回排队，并逐单列出冲突
- 同一时段按提交先后 FIFO；取消或改评级释放时段后，自动递给排队中的下一匹
- 列表筛选：待确认 / 可作业 / 已完成；完成与取消进入归档
- 数据保存在浏览器 localStorage

## 分层结构

- `src/domain/scheduling.ts`：纯规则层（风险评级、状态判断、重叠判定、FIFO 评估），无 React 依赖
- `src/lib/storage.ts`：存档层（localStorage 持久化 + 完成/取消归档 + 种子数据）
- `src/hooks/useSchedule.ts`：页面操作层（增单、确认、改评级、取消、完成与递补提示）
- `src/components/`：表单与列表 UI
