# hxyfront-62011 蹄铁师上门预约风险排程

蹄铁师上门时，踢踏或抬蹄不稳的马常与普通马混在同一时段，单人接单风险高。本项目在原修蹄档案页基础上补成预约风险排程。

## 功能

- 每匹马登记：马匹编号、抬蹄耐受（稳定 / 不稳 / 拒绝抬蹄）、最近 30 天踢踏史、所需助手人数、到场时段。
- 风险评级：抬蹄不稳/拒绝抬蹄，或近期有踢踏史，自动判为高风险。
- 高风险马必须由两名不同蹄铁师确认才能占时段；普通马单人确认即可。
- 同日时段重叠、助手未确认时退回「待确认」，卡片逐条列出冲突。
- 预约按入队时间 FIFO 排队；取消或改评级后原时段释放，排队中满足条件的下一匹自动递补并提示。
- 列表筛选：待确认 / 可作业 / 已完成（完成与取消归档）。

## 分层结构

- `src/scheduling/domain.ts`：纯函数状态判断（风险评级、时段重叠、排队占位、冲突清单、递补检测），不依赖 React 与存储。
- `src/scheduling/archive.ts`：localStorage 存档读写与演示初始数据。
- `src/scheduling/useSchedule.ts`：页面操作层（接单、双确认、助手确认、取消、改评级、完成、归档重置）。
- `src/scheduling/AppointmentCard.tsx` / `NewAppointmentForm.tsx`：页面组件，只渲染域层推导出的状态。
